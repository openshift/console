# OpenShift Console 5.2 Release Notes

## Changes to plugin API

### New `console.app/drawer` extension and `useAppDrawer` hook

Plugins can contribute a side panel that opens beside the Console page and pushes the page content
aside. Register the panel component with a `console.app/drawer` extension, then open, close, or
toggle it from your plugin's components by calling `useAppDrawer` with the extension's `id`.

- The panel component renders its own header and close button. Call the `onClose` prop to close the
  drawer.
- Console unmounts the panel when the drawer closes. Keep any state that must persist between
  openings, such as a chat history, outside the panel component.

See [`console.app/drawer`](../docs/console-extensions.md#consoleappdrawer) and
[`useAppDrawer`](../docs/api.md#useappdrawer) for details.
